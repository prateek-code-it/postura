# Postura — Portable Smart Spine Posture Monitoring Device

An IDP (Innovative Disciplinary Project) combining embedded systems and a
companion app to help office workers and students maintain better spine
posture, with real-time haptic feedback and ML-driven progress tracking.

## Status: TRL 4 (in progress)

- TRL 1–3: complete (research, concept, individual sensor testing)
- TRL 4: integrating full prototype + validating with dynamic user tests

## Repo structure
```bash
postura/
  ├── firmware/     Arduino/ESP32 firmware (posture detection + alerts)
  ├── app/          Web app (dashboard, trends, ML improvement report)
  └── docs/         Slides, diagrams, and project documentation
```


## Hardware

- ESP32 microcontroller (dual-core, BLE/Wi-Fi)
- MPU6050 IMU (head tilt / neckband)
- Flex sensor tail (2 in, upper-spine curvature)
- Coin vibration motor (haptic alert)
- LiPo 500mAh battery + TP4056 charging module

## Software

- `app/index.html` — web dashboard: live posture status, trends,
  and a daily improvement report generated by a linear regression trend
  model over historical posture scores. Soft blue theme, light/dark mode.
- Planned: React Native / Capacitor port for a real installable mobile app.
- Planned: BLE integration to replace simulated data with live device data.

## Posture thresholds

| Band     | Angle range | Behavior                          |
|----------|-------------|------------------------------------|
| Good     | 0°–15°      | No alert                           |
| Moderate | 15°–30°     | Logged, no alert                   |
| Poor     | >30°        | Vibration alert after 60s sustained |

## Roadmap

- TinyML on-device posture context classification (sitting/standing/walking)
- "Spine Health Score" dashboard with fatigue and long-term trend tracking
- Pilot testing in real offices and university classrooms
